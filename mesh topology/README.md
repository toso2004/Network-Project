#1. Description

The Mesh topology is a networking set up where every device is connected to every other device directly. It consists of multiple redundant paths which causes data to take different routes to reach its destination. The Mesh topology is very reliable, fault tolerant and offers high perfomance. However this topology is expensive and complex due to requiring lots of cables and ports. Mesh topologies are used in military communications systems.
